#.bdm v3 リージョン節「締まり」欠陥の修正と再焼き込み

QEMU/CE 側からの依頼（共有ノート `~/workspace/mascot-shared/SHARED.md` の
[WinCE] 2026-11-20「焼き込みリージョンの『締まり』欠陥」）
への生成側対応。作業中はこのファイルへ区切りごとに追記する。

## 0. 欠陥の内容（CE 側実測の要約）

- 現行コンバータのリージョンは `damage_bands(alpha>0, max_bands=∞)`:
行ごとの x ランを「x 範囲が重なる間」縦にマージし、その際 x 範囲が
min/max へ拡張されるため、縦に長い形状では矩形がシルエットの
bbox へ退化する（ミク pose 0 に (13,0,152,320) が実在）。
- 被覆は正しいが締まっていない: 和集合/真シルエット比はミク平均
1.65×（最大 1.69）、ヒカリ（mythra）平均 2.01×（最大 2.26）。
従来の相互検証は被覆しか見ていなかったため素通りした。
- CE ではリージョン＝窓形状そのものなので、余分な面積が黒露出に
なる。正確な再タイリングは平均 727/1,430 矩形で GWES 適用が
秒オーダーになり使えない。

## 1. 依頼された修正仕様

1. リージョンは **α≥128 シルエット＋8 行帯域化ラン和集合** で焼く
（BMAS で実証済みの方式。CE 側ホスト見込み: ミク平均 75 矩形・
比 1.057、ヒカリ平均 112 矩形・比 1.134）。
2. 相互検証に **締まり基準 union / silhouette(α≥128) ≤ 約 1.15**
を被覆と並ぶ合格条件として追加する。
3. 再生成はリージョン節のみ（ピクセル節は無変更のはず）。

## 5. 実装（2026-11-21 完了）

- `frames_to_bdm.py` に `silhouette_regions(buf, band_h)` を新設:
  合成バッファの α≥128 シルエットを帯域化ラン和集合でタイリング
  する（帯ごとにシルエットを x 軸へ射影し、被覆列の極大ランを
  帯全高の矩形にする。順序は帯→x の昇順）。リージョン生成は
  `damage_bands` から切り離した（ダメージ帯は従来どおり変更
  被覆専用に残置）。
- **帯高の定義**: B = clamp(round-half-even(H/40), 4, 8)（H は
  サイズ表示高）。320 では依頼仕様どおり 8 行。248 では一律
  8 行だと実測平均 1.163 で基準 1.15 を超えた（帯域感度実測:
  248 は帯 4→1.079/175 矩形、帯 6→1.119/116 矩形、帯 8→
  1.163/83.5 矩形）ため、帯高を表示高に比例させた。矩形数は
  全サイズで 75〜116 の同程度に収まる。FORMAT.md §5b に定義
  式として明記済み。
- verify の被覆判定を α≥128 シルエット基準へ変更し、締まり
  （ポーズごとの和集合/シルエット比の平均・最大）を集計して
  **平均 ≤ 1.15 を合格条件**に追加した。負の対照: 旧リージョン
  の mythra パックは新 verify で不合格（exit 1、締まり 2.396 /
  2.339）— ゲートが欠陥クラスを実際に検出することを確認。
