### 項目2 完了（フォント探索の cwd 相対問題の是正）

- 変更前: 探索順は 環境変数 BRAINUI_FONT_PATH → **cwd 相対の
  fonts/** → /usr/local/share → /usr/share。任意の作業ディレクトリ
  から起動された製品は bundled フォントを失っていた。
- 変更後（src/tk_font.c）: 環境変数 → **実行ファイル相対**
  （/proc/self/exe から導出: ../share/fonts/libbrainui2/、fonts/、
  ../fonts/）→ **ライブラリ相対**（dladdr で .so の位置から導出、
  同じ3候補）→ インストール先の絶対パス → cwd 相対は最後の保険。
  補完フォントは従来どおり主フォントのパスから導出される。
- 実装上の注意: _GNU_SOURCE は全 include より前に定義する必要がある
  （__GLIBC__ は features.h 読込前は未定義のため、当初 __GLIBC__
  ガードで囲って dladdr が無効化される失敗をした — 修正済み）。
  dladdr は glibc 2.34+ では libc 内（-ldl 不要）。ホスト 2.39 /
  ターゲット trixie 2.40+ ともに満たす。
- テスト: tests/test_font.c に test_bundled_search を追加（+6件）。
  fonts/ の無い一時ディレクトリへ chdir しても実行ファイル相対で
  読めること、環境変数が機能すること、無効な環境変数が素通りする
  ことを固定した。test_font: 28 passed, 0 failed（従来 22）。
- include/tk.h の Loading policy 記述も新しい探索順に更新した。

- **参照の裏取り**（androidx material3、M21 取得の実装ソース +

  - NavigationBar.kt の計測コード: ピル幅 = アイコン幅 +

    2×IndicatorVerticalPadding。ピルはアイコンと同中心に置かれ、

  - ベースライン M3 仕様図: アクティブインジケーター 64×32dp、
    アイコン 24dp、ピルとラベルの間 4dp（出典:
    material-components-android 公式ドキュメント
    BottomNavigation.md の M3 Expressive 対比表、および
    m3.material.io 仕様転記。取得 2026-11-21）。
  - **64 か 56 か**: 現行 androidx 開発ブランチのトークンは
    56dp 幅（M3 Expressive 移行途上。公式ドキュメントも
    「Active indicator: From 64dp to 56dp」と明記）。本バーの
    実装前提はベースライン形（Tall コンテナ 80dp 系）であり、
    指示文の値とも一致する **64×32dp を正**とした。56dp は
    Expressive 移行時の候補として AUDIT §23 に記録した。
- **原因**: ピル形（mode 1）は M7 から存在したが、既定は mode 0
  （セル全面のトーナル面）で、生産側の呼出元が皆無だった
  （set_indicator_mode の呼出はテストのみ）。撮影でも全面楕円が
  出ていた。バー自体が全面バーである点は参照（NavigationBar も
  全面が標準）と一致しており、浮動化はしていない。撮影ハーネスは
  バーを素の背景に置くため浮いて見える場合があるが、実シェルの
  パネルはシェル側の別実装で、本是正の対象はライブラリ部品。
- **変更**（src/tk_widgets.c、include/tk.h）:
  - tk_bottombar_new の既定を mode 1 に変更。mode 0 は明示選択の
    旧形として残置（API 互換）。
  - ピル寸法を固定 64×36px から nav_pill_rect に集約:
    幅 = アイコン幅 + 45px（20dp×2 の換算）、高さ = アイコン高
    + 9px（4dp×2 の換算）、上端 = アイコン上端 − 4px、半径 =
    高さ/2（CornerFull）。参照アイコン 27px（24dp）では
    72×36px = 64×32dp 換算と一致。バー描画
    （tk_bottombar_paint_indicator）とボタン描画の両経路に適用
    （レール/ドロワーのピル表示も同形状に揃う）。
  - ラベルは従来どおりアイコンの下（ピルの外）。ピル下端から
    ラベルまでの間隔は共有のアイコンセル配置由来で 3px
    （参照 4dp = 4.5px）— デスクトップアイコンと共有する
    配置のため本弾では変更せず、微差として記録する。
