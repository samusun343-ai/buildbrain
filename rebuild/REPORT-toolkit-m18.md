### コピー/オーバーヘッド削減

- 本弾の変更は寸法値・フェード値・レイアウト
  フラグのみで、描画経路にコピーを追加して
  いない。tk_dialog_title_h() は measure /
  arrange / paint の3箇所が個別に持っていた
  標題帯の計算を1関数に寄せた（重複計算の
  削減であり、結果は同一）。
- Toast の caption メトリクス化はレイアウトと
  描画で同じ _st 計測を使う形にし、二重計測を
  増やしていない。
- テストは新規ファイル1本の追加のみで、既存
  テストの実行時間・メモリに変更はない。

### キャッシュ/メモリ管理

- ライブラリ側に新規キャッシュ・静的バッファを
  追加していない。追加した easing 関数2本は
  純関数（状態なし）。tk17 は実行時にキャンバス
  を都度確保・解放する既存テストと同じ方式で、
  常駐メモリへの影響はない。

### 実機の現実への対応

- 寸法は全て実機（800×480・187ppi・抵抗膜
  1本指）の換算で確定した: dp ×1.16875 /
  epx ×1.43 の既存規則を全照合に適用し、56px
  のタッチフロアを割る変更はしていない（F3 の
  47px は参照部品自体の高さであり、セグメント
  のタップ領域は行全体に取る既存の当たり判定
  のまま）。
- 永続化・リセット耐性に関わる変更はない
  （本弾は寸法と遷移のみ）。時刻依存の新規
  ロジックもない（フェードはアニメーション
  クロック駆動で、実時刻の有効期限等は導入
  していない）。
