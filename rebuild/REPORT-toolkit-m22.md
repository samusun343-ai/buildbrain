## 5. WinUI dark 面ラダーの是正

§9.1 のプローブ方法（各トークンを bg へ合成し
round-to-nearest で RGB565 化）で再現した潰れ:
是正前は surface / card_bg / subtle / control_fill
等が 0x2965 に、別群が 0x2945 に collapse していた。

是正（tk_theme_winui_dark の白オーバーレイ α）:
selection 15→18、container 15→18、
container_highest 40→42、subtle 40→46、
card_bg 40→46、control_fill 15→17、
control_fill2 13→24、border 15→25。
狙い: 隣接段が 565 の別ステップに乗り、かつ
24bit 値の参照からの乖離を最小化（α の変更量は
+2〜+11、最大の subtle / card_bg で +6/255 ≈
2.4%）。段の順序（暗→明）は参照どおり保存。

是正後の 565 ステップ（実測）: bg 0x2104、
control_fill_dis 0x2925、surface_alt / layer
0x2945、surface 0x2965、card_bg / selection /
subtle 0x3186、control_fill 0x31a6、
control_fill2 0x39a7、border 0x39c7、
container_highest 0x39e7。意味を担う入れ子対
（面×カード、面×subtle、面×選択、面×操作塗り、
カード×操作塗り、境界×カード 等）は全て別
ステップに分離。この検証を test_tk5 の
test_winui_dark_ladder565 として固定した
（同じ合成・量子化方法でステップ値と分離を
アサート）。light 側は §21 の整理どおり
（参照固有の近接）調整対象外。

## 6. 未検証項目の処理

(a) チェックグリフのパス比率照合: material3 の
チェック比率座標（相対 (0.15, 0.55) /
(0.45, 0.85) / (0.85, 0.25)、M21 §5.3 で抽出）と
当方の 21px 箱グリフを画素プローブで照合。
旧パスは長い腕の上端が比率座標より左・上に
寄っており（頂点 x ≈ +14 に対し比率では +15）、
不一致を確認。パスを比率座標どおりに再定義し
（paint_check_glyph、21px 箱・28px 箱の両形態に
適用）、再プローブで腕・頂点の画素一致を
test_tk17 に固定した。fit 撮影（§3）でも
チェックとして読めることを目視確認。

(b) メニュー項目高の突き合わせ: 当方の項目高は
control_h = 54px（menu_row_h）。参照の従来型
項目高は 48dp（material3 Menu.kt の
MenuListItemContainerHeight）で、新換算では
53.8 → 54px となり一致。Expressive 型の 44dp は
当方のメニュー形態（従来型）の対象外。WinUI
テンプレートには固定項目高が無く（Padding
8+9epx ＋ テキスト行）、共有 control_h 行は
構造的差異として記録する（コードコメントにも
M22 collation として明記）。

(c) WinUI スライダードットの状態スケール:
裏付けあり（M21 §5.1 のテンプレート抽出:
基準 12epx に対し rest 0.86 / hover 1.167 /
pressed 0.71）のため実装した。×1.344 で基準
16.1px、状態径は 14 / 19 / 11px。単体・Range
両形態のアクティブつまみに適用。test_tk17 に
状態別の実測ピンを追加（つまみ中心列の accent
連続長で測定。なお浅い配置ではドラッグ中の
値バブルがキャンバス上端にクランプされて
つまみに重なる既存挙動があるため、テストは
深い配置で測定）。

## 7. Switch の状態可変つまみ径

実装した（見送りなし）。material3 Switch の
つまみ径（M21 §5.3 確定: 未選択 16dp / 選択・
アイコン有 24dp / 押下 28dp）を ×1.12 で
18 / 27 / 31px とし、tk_switch_paint に適用。
- 選択径はスライドアニメーションの knob_pos で
  補間（18 → 27）。
- 押下径のため tk_switch_event にポインタ
  DOWN / UP の pressed 処理を追加（従来は UP で
  切替のみで、押下中の状態が存在しなかった）。
  押下中は目標端に依らず 31px。
- 未選択時の外形リング（outline 径＋2）は
  つまみ径に追随。WinUI 形態は参照どおり固定
  22px のまま不変。
- test_tk17 に3状態の実測ピンを追加
  （中心行の surface 色連続長で測定:
  off 18 / pressed 31 / on 27）。
